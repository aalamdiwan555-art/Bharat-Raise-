# Bharat Rise — Full Unity Game
Self-contained mobile city-building strategy game. Build Homes, Farm, School, Solar, Hospital and Market districts; manage money, population, food, energy and happiness; advance years and reach Level 10.
Unity 2022.3 LTS. Built-in pipeline. UGUI/TextMeshPro. Android-friendly portrait UI. Local save.
Open the repository as a Unity project. The editor automatically creates and registers the first scene.
Store publishing still requires the developer's own package ID, signing key, store listing and account-owned credentials; these are intentionally not hard-coded.
