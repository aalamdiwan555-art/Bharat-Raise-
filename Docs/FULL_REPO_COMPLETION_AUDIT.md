## Current repository limitation
The repository contains code and build automation, but it does not currently contain a complete production art/audio asset library or a signed release artifact. The scene files are generated by editor code rather than confirmed committed YAML scenes. Therefore this repository should currently be treated as a development foundation, not as a verified 100% store release.
