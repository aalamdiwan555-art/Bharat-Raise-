# Bharat Rise release checklist
1. Open with Unity 2022.3 LTS.
2. Wait for automatic scene generation/import.
3. Use Bharat Rise > Build All Scenes.
4. Use Bharat Rise > Configure Android.
5. Set your own Android keystore/signing credentials.
6. Review package ID com.bharatrise.game and change if required.
7. Build APK for testing; build AAB for Google Play.
8. Test fresh install, save/load, rotation policy, back navigation, low-memory restart and offline play.
9. Add store icon, screenshots, privacy policy and age/content declarations.
10. Add ads/analytics only with your own account credentials and consent configuration.
